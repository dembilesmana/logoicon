## 1. Tambahkan SVG

Letakkan SVG baru di direktori brand yang sesuai di `packages/core/assets`. Gunakan `icon` untuk simbol atau mark tanpa wordmark, dan `logo` untuk logo lengkap yang menyertakan wordmark atau lockup resmi.

{/* Nama file mengikuti format `[logo|icon]-[mono]-[light|dark].svg`: */}
{/* Nama file mengikuti format regex `/^(logo|icon)(-mono-(light|dark)|-(light|dark))?\.svg$/`: */}

<Card title="Konvens penamaan aset">

<Aside type="tip">

| Varian          | Pola nama                             | Contoh                                          |
| --------------- | ------------------------------------- | ----------------------------------------------- |
| Berwarna        | `[logo\|icon].svg`                    | `logo.svg`,<br/>`icon.svg`                      |
| Berwarna mode   | `[logo\|icon]-[light\|dark].svg`      | `logo-dark.svg`,<br/>`icon-light.svg`           |
| Monochrome mode | `[logo\|icon]-mono-[light\|dark].svg` | `logo-mono-dark.svg`,<br/>`icon-mono-light.svg` |

</ Aside>

<Aside type="danger">

| Varian     | Pola nama               | Contoh                               |
| ---------- | ----------------------- | ------------------------------------ |
| Monochrome | `[logo\|icon]-mono.svg` | `logo-mono.svg`,<br/>`icon-mono.svg` |

</Aside>

</Card>

Jangan gunakan suffix `-mono` untuk aset berwarna. Jika aset monochrome memiliki versi untuk latar terang dan gelap, beri suffix `-light` dan `-dark` agar kedua varian dapat dibedakan. Suffix tersebut harus berada setelah `-mono`.

## 2. Jalankan generator Core

Dari root repository:

```bash
npx turbo run generate --filter=@logoicon/core
```

Generator menghapus output lama lalu memproses semua file dari `assets` ke `.assets`. Jika ada SVG yang tidak valid, proses akan berhenti dan error perlu diperbaiki sebelum lanjut.

## 3. Generate komponen React

```bash
npx turbo run generate --filter=@logoicon/react
```

Langkah ini membaca ekspor aset Core, membuat file `.tsx`, index export, dan metadata React di `packages/react/.dist`.

## 4. Validasi

Jalankan pemeriksaan tipe dan build yang relevan:

```bash
npm run check-types
npx turbo run build --filter=@logoicon/react
```

Output `.assets`, `.dist`, dan `dist` adalah artefak build yang diabaikan Git. Jangan menambahkan hasil generate tersebut secara manual kecuali workflow repository memintanya.
