---
title: Instalasi
description: Pasang package LogoIcon untuk aplikasi React.
---

Pastikan project sudah menggunakan React. Pilih package manager yang digunakan project:

import { TabItem, Tabs } from "@astrojs/starlight/components";

<Tabs>
  <TabItem label="npm" icon="npm">

    ```bash
    npm add @logoicon/react
    ```

  </TabItem>
  <TabItem label="pnpm" icon="pnpm">

    ```bash
    pnpm add @logoicon/react
    ```

  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">

    ```bash
    yarn add @logoicon/react
    ```

  </TabItem>
</Tabs>

Setelah instalasi, lanjutkan ke [panduan penggunaan komponen React](guides/react/usage). Untuk detail seluruh ekspor package, lihat [referensi API React](reference/react-api).
