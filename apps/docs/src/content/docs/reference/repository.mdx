```text
apps/
  docs/           Situs dokumentasi Astro + Starlight
  web/            Katalog dan pencarian ikon Next.js
packages/
  core/           Aset SVG dan generator aset
  react/          Generator serta paket komponen React
  util/           Utilitas nama dan className
  logger/         Logger lintas paket
  config/         Konfigurasi aplikasi umum bersama
  eslintconfig/   Konfigurasi ESLint bersama
  tsconfig/       Konfigurasi TypeScript bersama
```

## Batas tanggung jawab

- Ubah aset sumber di `packages/core/assets`, bukan output `.assets`.
- Ubah generator dan AST React di `packages/react` jika format komponen perlu diperbaiki.
- Ubah isi situs ini di `apps/docs/src/content/docs`.
- Ubah konfigurasi navigasi dan judul situs di `apps/docs/astro.config.mjs`.
- Gunakan `apps/web` untuk perilaku katalog, filter, dan preview ikon.

## Artefak yang diabaikan

Direktori `node_modules`, `.turbo`, `.assets`, `.dist`, `dist`, dan `.next` adalah output lokal atau
cache. Artefak tersebut dibuat ulang oleh script build dan tidak perlu diedit langsung.
