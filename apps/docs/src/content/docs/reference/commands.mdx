---
title: Perintah workspace
description: Referensi perintah pnpm dan Turborepo yang tersedia di repository.
---

Jalankan semua perintah berikut dari root repository.

| Perintah                                                | Fungsi                                             |
| ------------------------------------------------------- | -------------------------------------------------- |
| `pnpm install`                                          | Memasang dependency semua workspace.               |
| `pnpm dev`                                              | Menjalankan web dan docs dalam mode watch.         |
| `pnpm build`                                            | Build workspace yang ditargetkan oleh script root. |
| `pnpm check-types`                                      | Menjalankan pemeriksaan TypeScript.                |
| `pnpm lint`                                             | Menjalankan lint pada workspace.                   |
| `pnpm format`                                           | Memformat file TypeScript, TSX, dan Markdown.      |
| `pnpm exec turbo run generate --filter=@logoicon/core`  | Generate aset Core.                                |
| `pnpm exec turbo run generate --filter=@logoicon/react` | Generate komponen React dan metadata.              |
| `pnpm --filter docs build`                              | Build situs dokumentasi saja.                      |

Gunakan filter Turborepo untuk membatasi pekerjaan ke paket tertentu dan menghindari build aplikasi yang tidak terkait.
