LogoIcon menyediakan ikon brand dalam format SVG. Gunakan SVG langsung dari <a href={config.url.web} target="_blank" rel="noopener noreferrer">Katalog LogoIcon</a>, atau gunakan package React jika ingin mengimpor ikon sebagai komponen.

## Pilih cara penggunaan

- **SVG langsung**: salin atau unduh aset dari katalog tanpa memasang dependency. Ikuti [panduan penggunaan SVG](guides/basics).
- **Komponen React**: package `@logoicon/react` menyediakan komponen dan metadata ikon. Mulai dari [instalasi React](guides/react/installation), lalu lihat [contoh penggunaannya](guides/react/usage).

Package saat ini hanya mendukung React. Integrasi untuk framework lain belum tersedia.

LogoIcon dirilis di bawah lisensi MIT. Source code dan issue tracker tersedia di [repository GitHub](https://github.com/dembilesmana/logoicon).
